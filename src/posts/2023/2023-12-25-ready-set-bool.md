I implemented a series of boolean algebra and set theory exercises in C++
(CMake, clang-tidy): a bitwise adder and multiplier, Gray code, a truth table
generator, a propositional formula evaluator, negation and conjunctive normal
forms, a SAT checker, powersets, set evaluation and a space-filling curve
mapping, each with its own tests.

**Language:** C++
