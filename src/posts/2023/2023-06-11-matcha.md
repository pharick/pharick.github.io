I built matcha for the École 42 web branch: a dating site with e-mail
verification, profiles with tags, photos and location, a suggestion list matched
on both users' preferences, likes that turn into matches, private chat between
matched users, and live notifications. The API is Go with the goji router over
`database/sql`, the frontend is Next.js 13 with the App Router, and nginx fronts
both from one `docker compose up`.

The subject asks for hand-written SQL rather than an ORM, so I made the database
do the interesting work. Search is a single parameterised statement that filters
on mutual gender preference, age, popularity relative to the current maximum,
distance and blocks, and sorts by distance, age, fame or number of shared
interests. Two migrations add a PL/pgSQL haversine `calc_distance` on `POINT`
columns and an `array_intersect` function, so the interest sort is
`array_length(array_intersect(...))` inside the query. Pagination is snapshot-
stable: the client sends the time of its first request and rows updated after it
are excluded, which keeps infinite scroll consistent while ratings change
underneath.

For real time I used the gorilla/websocket hub pattern: one goroutine owns the
client maps and serialises registrations and deliveries through channels, each
client has a buffered send channel and slow clients are evicted instead of
blocking the hub. Chat clients are keyed by the `from.to` pair so a message
reaches both ends of a conversation and nothing else; the notifications hub
doubles as presence. Handlers return `(any, error)` and a single wrapper maps
validation errors, HTTP errors and unexpected errors to responses. JWTs carry a
`target` claim so activation and reset links cannot be replayed as sessions.

On the frontend, every API call is a server action that reads the token cookie,
so the browser only speaks to the two WebSocket endpoints and static uploads.
ESLint runs with the strict type-checked rule sets and Prettier with the
Tailwind plugin. There are no automated tests, the seed data depends on an
external API, and the repository was published as a single commit.
