I built Matcha, a dating web application, with a Go API (goji router, JWT auth,
PostgreSQL migrations, WebSocket hub) and a Next.js 13/React/Tailwind frontend,
run together with docker-compose. Features covered by the code include profiles
and photos, tags, geolocation-based search and distance, likes, visits, blocks
and reports, notifications and real-time chat.
