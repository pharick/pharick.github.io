libft is the first École 42 project and the library I reused in every later C
project at the school. It reimplements a subset of the C standard library and
adds a few helpers the curriculum asks for, compiled into a static archive with
-Wall -Wextra -Werror.

The mandatory part contains 34 functions: the memory routines (memset, bzero,
memcpy, memccpy, memmove, memchr, memcmp, calloc), the string routines (strlen,
strlcpy, strlcat, strchr, strrchr, strnstr, strncmp, strdup, atoi), the
character-class tests, and the allocating helpers substr, strjoin, strtrim,
split, itoa and strmapi, plus four functions that write to a file descriptor.
The bonus adds nine operations on a singly-linked list: new, add front and back,
size, last, delone, clear, iter and map.

I paid attention to the edge cases that the real functions define. memmove picks
the copy direction from the relative position of the buffers so overlaps are
safe; strlcpy and strlcat follow the OpenBSD contract, always terminating the
destination and returning the length they tried to create, including the dstsize
of zero case; itoa widens to long so INT_MIN works; split counts tokens first,
allocates once and frees everything already built if a later allocation fails;
lstmap clears the partial list with the caller's delete function on failure;
calloc sets errno to ENOMEM.

The layout is the one the norm requires: one function per file, functions of at
most 25 lines, no for loops, everything declared in libft.h, and a Makefile with
the standard all, bonus, clean, fclean and re targets.

There are no unit tests in the repository; the library was checked with the
school's testers at the time. calloc does not guard against multiplication
overflow and atoi mirrors the standard function without overflow detection. My
later projects (minishell, malloc, ft_nm) carry extended copies of this library
with strcmp, realloc, get_next_line and list helpers added.
