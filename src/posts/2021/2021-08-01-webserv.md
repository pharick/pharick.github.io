I built an educational HTTP server in C++ as an École 42 project. It handles
client connections with poll-based I/O multiplexing, serves static files,
supports GET, HEAD, POST and chunked request bodies, and is driven by a
configuration file that can declare multiple virtual servers with prefix- or
extension-based locations. It can also forward requests to CGI scripts.
