a drum kit, a clock, CSS variables, array cardio, a flex gallery, an AJAX type-
ahead, canvas drawing, dev-tools tricks, multiple checkboxes, a custom video
player, a Konami code and slide-in-on-scroll. Each exercise is a standalone
HTML/CSS/JS folder with ESLint configured for the project.
