In January 2018 I did the first thirteen of Wes Bos's thirty JavaScript30
challenges, each a small browser project in plain HTML, CSS and ES2015
JavaScript with no framework and no build step. The folders cover a keyboard
drum kit, a CSS clock, live CSS variables, two rounds of array-method drills, a
flexbox gallery, an Ajax type-ahead, canvas drawing, the console API, shift-
click checkbox ranges, a custom video player, key-sequence detection and slide-
in-on-scroll images.

The video player is the largest piece: play/pause, skip buttons configured
through `data-skip`, volume and playback-rate sliders served by one handler that
writes `video[this.name]`, and a progress bar that supports both click and drag
scrubbing through a small mousedown/mousemove/mouseup state. The key-sequence
detector keeps a rolling buffer of the last N keys with a single `splice` and
compares it to the secret string on every `keyup`. The drum kit releases its
pressed animation on `transitionend` instead of a timer, and the checkbox
exercise implements Gmail-style shift selection in sixteen lines.

I added an ESLint 4 configuration - `eslint:recommended` with two-space
indentation, single quotes and required semicolons - and BEM class names
throughout the CSS.

Challenges 14-30 are not here. Three exercises depend on external URLs for data
or video. Early learning code, kept as a record.
