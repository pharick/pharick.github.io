This repository holds my solutions to a two-year introductory C++ course: 65
lesson folders with about 500 stand-alone programs and roughly 16,600 lines,
committed together in May 2019. `1-year/` goes through procedural basics
(conditions, loops, digit manipulation, arrays, pointers, dynamic and 2D arrays,
file I/O) and `2-year/` through object-oriented C++ (structs, classes,
constructors and copy semantics, operator overloading, friends, templates,
inheritance, virtual functions) before ending on `std::string`, `std::vector`
and `<algorithm>`. Every file is a single program with its own `main()` that
reads from standard input, so any one can be compiled on its own with `c++
-std=c++11`.

The pieces I would point to are the ones where the exercise grew into something
with structure. `1-year/34-tetris` is a terminal Tetris with non-blocking
ncurses input, pieces as 4x4 rotation tables and separate collision checks
against walls and the field (one piece type is wired up so far).
`2-year/23-string-class/string.cpp` is a `String` class over a raw `char*` with
copy constructor, assignment, stream operators, `[]`, `()`, `+`, `*` and all six
comparisons. `2-year/24-templates/d.cpp` is a generic `Array<T>` with template
friend stream operators and a full `Array<char>` specialization, driven by a
`Fraction` type compared by cross-multiplication. `2-year/26-virtual-
functions/geo-5.cpp` draws rectangles and circles, hollow or filled, through an
abstract `Figure` with a polymorphic `draw()`. `2-year/19-modules/4-litavia-
bank-modules` splits a bank simulation into `Account`, `Order` and `Bank`
modules with headers and a command loop.

The code is early-learning code and I keep it as a record: `using namespace
std`, fixed-size buffers and C strings dominate until the last lessons, memory
is managed with `new`/`delete` by hand, comments are in Russian, and there is no
build system in the repository (a CMake project was used locally and is git-
ignored) and no tests. The whole collection was committed at once, so there is
no per-exercise history.
