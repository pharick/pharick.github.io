I wanted a CV that is not a frozen list of skills but a diary: a timeline of
what I actually did, when, and what I took away from it. So this site exists.

It is built with [Eleventy](https://www.11ty.dev/), a small static site
generator. Every entry is a Markdown file with a bit of front matter, and a
GitHub Actions workflow builds and publishes the site on each push.

The first batch of entries is my public GitHub history: the École 42
curriculum, the courses and exercises before it, and the more recent OCaml
and graphics experiments. Those entries are dated by when each repository
was created on GitHub, so treat the dates as "started around", not "finished on". From here on, the plan is simple: build, read,
learn, write it down.
