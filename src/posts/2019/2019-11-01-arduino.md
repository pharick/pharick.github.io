These are the eight sketches I wrote for an introductory microcontroller course
in November 2019, one `.ino` file per lab: blinking LEDs, buttons driving a
counter, a PWM breathing LED, potentiometer-controlled fading, a two-digit
7-segment display, the same display through a 74HC595 shift register, an RGB LED
cycling through hues, and a photoresistor with smoothing.

The rule I set myself was to never call `delay()`. Every sketch keeps `unsigned
long` timestamps and compares them against `millis()`, so `loop()` keeps polling
inputs while outputs animate. That matters most in `5-segments`, where two
timers run at once: one advances the counter every second and the other switches
the active digit every millisecond, multiplexing the two digits from the same
eight segment pins.

The shift-register version (`6-shift`) shows the payoff of moving the segment
patterns into data: eighty `digitalWrite` lines in the direct-drive version
became a ten-byte glyph table and a single `shiftOut()`. The RGB sketch converts
a 0-1535 hue into duty cycles by splitting it into six 256-step zones, and the
button sketch only counts a rising edge that arrives at least 200 ms after the
previous one.

This is early learning code and I keep it as a record. There are no build files
beyond the sketches themselves; each one is uploaded from the Arduino IDE.
